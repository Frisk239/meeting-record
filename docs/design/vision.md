# 愿景与完成边界

> **相关：** [ADR 0003](../adr/0003-cpu-asr-and-llm-summary.md) · [ADR 0004](../adr/0004-speaker-diarization-p0-cpu.md) · [DESIGN.md](./DESIGN.md)

## 产品一句话

个人可用的会议纪要工具（显示名默认 **Meeting Record**，可配置）：在 **CPU** 上把录音/音视频转成 **带说话人标签的文字**，再用 **LLM** 整理成可编辑纪要。

## 谁用 · 什么场景

| 角色 | 场景 | 成功长什么样 |
|---|---|---|
| **个人用户（默认仅一人）** | **现场实际录音**（当面沟通/线下会；非腾讯会议系统声为主） | 一点开始录 → 长按结束 → 自动上传转写 |
| 同一用户 | 会后上传已有音视频 | 同样进入转写 + 纪要 |
| 同一用户 | 在 **4 核 4G 无 GPU** 上跑 **自托管 Web** | 串行跑完；可接受会后等待 |
| 同一用户 | 手机或电脑浏览器 | **一套响应式 Web** |

## 核心用户路径（North-star path）

1. 浏览器打开 Web App → **采集（主路径=现场麦录音）**：  
   - **P0 浏览器内录音**：点击开始 → **长按确认结束** → **自动上传**；或  
   - **P0 文件上传** / 追加录音（对标智在「导入音频 / 追加录音」）。  
2. **Transcription Job**（CPU）：ASR + **Diarization** → 带 Speaker 的 **原文/Transcript**（可按时间/发言人浏览；失败可降级）。  
3. 转写 **成功后自动** **LLM → Minutes（AI总结）**；可手动重新生成 /「换角度总结」。  
4. **阅读 / 编辑**详情：主 Tab **纪要 · 原文 · 外脑（按需）**；纪要内**右下角进追问子页**；Speaker 展示；改名可后置。**无探索 Tab。**  
5. **导出 P0：Markdown + PDF**（纪要为主；可选附带原文）。

## 完成边界

### 要做（In）

- 单人使用  
- **自托管 Web App**（响应式：手机 + 电脑）  
- **用户系统（简单）**：注册 + 密码登录；是否开放注册仅由**服务端配置**控制（前端不出现该开关）；数据按用户隔离  
- **API 必须鉴权**：未登录不可调用业务接口；按资源属主防越权（IDOR）  
- **LLM 设置 UI**：用户可配置 OpenAI 兼容的 `base_url`、`model_id`、`api_key`（亦支持部署级 env/配置文件）  
- **浏览器内录音（P0）**：现场麦；点击开始 · 长按确认结束 · 自动上传；**文件上传 / 追加录音（P0）**  
- 上传后串行任务 → **带 Speaker 的转写**（P0，ADR 0004）  
- **转写成功 → 自动生成 Minutes**（智在式模块，见上表）  
- 详情 **纪要 · 原文 · 外脑(按需)**；**追问=纪要子页（右下角）**；**无探索**  
- CPU FunASR 方向（SenseVoice/轻量 ASR + VAD + CAM++）  
- LLM 文本总结（优先 API）  
- Claude 气质 UI（IA 可参考智在，视觉不抄）  
- **导出：Markdown + PDF（P0）**  
- **LLM 记忆：分层 Context Pack**（待办/争议等全量；长转写摘要+片段 — ADR 0005）  
- **存储：本机磁盘 + SQLite**  
- **显示名默认 Meeting Record**（`APP_NAME` 可配）  
- **技术栈：TypeScript 全栈**；**Vite + React · Hono · Drizzle/SQLite · pnpm**；**Python 仅 ASR 等必要旁路**（ADR 0009–0012）  

### 明确不做（Out）— 当前阶段

- GPU / MOSS 默认引擎  
- pyannote/WhisperX 重流水线默认  
- 纯 LLM 充当唯一 Diarization  
- 飞书级组织权限、OAuth/企业 IdP、复杂 RBAC、计费多租户 SaaS  
- 日历 bot、硬件麦矩阵  
- 会中实时字幕 SLA  
- 默认把原始音频交给第三方（云 LLM 优先只传文本）  
- 「只靠前端藏 URL、API 无鉴权」  
- 将「桌面系统声 + 麦环回」当作纯 Web 首版必达（无额外助手时浏览器能力有限）

## 约束与偏好

| 项 | 选择 |
|---|---|
| 算力 | 无 GPU · **4 核 4G** · 单人 · 串行 Job |

| 纪要智能 | LLM 文本；4G 上优先 API |
| UI | [DESIGN.md](./DESIGN.md)（Claude） |
