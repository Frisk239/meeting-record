> 问题：完整产品路径在 Claude 气质下长什么样？能否作为开发与验收对照？

## 一键打开

```bash
# 任选：用浏览器直接打开
start docs/design/prototype/mvp/index.html   # Windows

# 或本地静态服务（推荐，避免部分浏览器 file 限制）
cd docs/design/prototype/mvp && python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

## 覆盖页面

| 路由 hash | 页面 |
|---|---|
| `#/login` | 登录 |
| `#/register` | 注册（是否可用由服务端决定；原型默认模拟开放） |
| `#/home` | 会议列表 + 录音/导入 |
| `#/record` | 录音中（点开始模拟 · **长按结束**） |
| `#/meeting/:id` | 详情：纪要 \| 原文 \| 外脑 |
| `#/meeting/:id/ask` | 追问子页（从纪要右下角进） |
| `#/settings` | 账号摘要 + LLM 三字段配置 |

## 响应式导航

| 断点 | 导航 |
|---|---|
| **手机**（&lt;900px） | 底部三键：**笔记 · 录音(中间大钮) · 我的**；录音页沉浸式隐藏底栏 |
| **电脑**（≥900px） | 顶部栏：品牌 · 笔记/录音/我的 · **用户名头像**（无开始录音 CTA）；列表双列 |

录音入口：**仅导航「录音」**。导入：**笔记页 / 原文页「导入音频」→ 系统文件选择器**。
## 交互说明

- 录音：**开始** → 计时/波形 → **长按「结束并上传」约 0.8s** → 自动进入详情并模拟转写进度 → 自动生成纪要  
- 外脑：默认空态，点 **「生成外脑」** 才出现内容  
- 导出：弹出 mock 下载提示（MD/PDF）  
- **`ALLOW_REGISTER` 不出现在前端**（仅服务端配置）
