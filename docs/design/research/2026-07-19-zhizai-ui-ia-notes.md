## AI外脑 Tab（截图续 · 仅作参考，本仓不默认自动生成）

智在在「AI外脑」下会**自动**产出扩展解读，例如：

| 块 | 内容形态 |
|---|---|
| 主题小标题 | 如「大三下实习动员与毕业预警」 |
| **逻辑** | 对整场会议结构的再叙述（几部分、谁补充了什么） |
| **字数** | 如约 150 字（生成篇幅元数据） |
| **核心洞察** | 更「评述/感受」向的洞察（语气主观，非纯纪要） |
| **价值火花（编号条目）** | 如「1. 价值火花：…」；含**标题**、正文、**为什么有效？** 分点；偏职场/认知升维解读，超出干纪要 |
| **逻辑深渊（编号条目）** | 如「2. 逻辑深渊：…」；含**标题**、矛盾分析、引用原话、**直接后果** / **连锁反应** 等推演 |
| **认知高利贷（编号条目）** | 如「3. 认知高利贷：…」；含**标题**、隐喻式批判、**本质原因** 等；强评述、非会记 |
| **心理暗流（编号条目）** | 如「4. 心理暗流：…」；含**标题**、对语气/警告的解读、**权力场域分析** 等；强评述 |
| **建议（章节）** | 针对分析出的问题给处方；编号条目均含**多步落地**（第一步/第二步/…）。例：1 建议→任务；2 B 计划熔断；3 用「能力清单」替代「项目数量」；4 建立「魔鬼代言人」打破虚假共识 等 |
| **沟通话术** | 可直接复制发给第三方的成稿（如给辅导员/教秘的一段话）；包装方案与请求协作 |
| **思想发芽** | 共情式处境解读 + 发散思考；强个人化评述，非会记 |
| **思想发芽·编号小品** | 如「1、种子的沉默」「2、时间的裂缝」：会中原话 → 隐喻 → **跨界故事**；可夹 **Aha瞬间** 金句框；离会记最远 |
| **Aha瞬间** | 灯泡块：跨界故事后的抽象顿悟句；非会记字段 |

→ **本仓决策不变：**

1. **不**在转写成功后自动跑「AI外脑」全页灌屏。  
2. 外脑 Tab 可保留，内容**仅用户显式生成**。  
3. **追问**作为纪要子页（右下角）；可问逻辑结构/洞察等。  
4. **探索**不做。| 原文 | 转写全文 + 播放 | **P0** Transcript 阅读 |
| 探索 | 扩展探索 | **砍掉** |
| 追问 | 底栏/对话 | **纪要子页**，右下角进入 |

## AI总结 Tab（模块）

### 纪要头（截图续 · 传统会议纪要字段）

小节标题「**纪要**」，字段化展示：

| 字段 | 示例/说明 |
|---|---|
| 会议主题 | 标题文案 |
| 会议时间 | 录制/开会时间 |
| 会议地点 | 可从上下文推断；不明则写「根据上下文未明确」 |
| 参与主体 | 人物 + 角色说明（可对应 Speaker 映射） |
| 会议核心目标 | 一段话目标陈述 |

→ 本仓 Minutes **P0 应含此元信息头**（地点可空）。

### 正文模块（列表型）

- **关键议题内容**（分节 + 要点）  
  - 章标题居中可导航（如「关键议题内容」）  
  - **编号议题**（1、实习要求与规范）  
  - **子标题**（实习时间与学分）  
  - **要点 bullet**（可含日期、学分、特例专业等细则）  
- **争议点**  
  - 小节标题「争议点」  
  - **引用块**（大引号样式）：一段话概括分歧/张力，可嵌入多人观点与数字  
  - 无争议时可空段  
- **待办事项**  
  - 章标题居中「待办事项」  
  - bullet：**责任人/角色前缀** + 动作描述（如「美萍老师：将…发给…」）  
  - 可含协作链（转发至群、请某人协助等）  
- **时间轴内容回顾**（时间戳 + 小节标题 + 段落）  
- 底栏：**换角度总结**（展示当前模板名，如「通用会议」）· **追问**
## AI总结 · 图解式视图（截图 2026-07-19 续）

同一「AI总结」Tab 下除列表型（议题/争议/待办/时间轴）外，还有 **图解/信息图** 形态：

| 元素 | 说明 |
|---|---|
| 会议标题 | 大标题 +「会议纪要」 |
| 元信息 | 录制时间 · 类型（语音） |
| 一句话横幅 | 浅黄底：会议围绕…进行说明 |
| **流程/阶段条** | 如「实习核心要求」三节点时间线（时间节点 / 材料规范 / 形式说明） |
| **双栏提示卡** | 合规要求（绿）· 风险提示（橙）等标签卡片 |
| **多色信息块** | 如「毕业关键节点」四宫格/多卡 |
| 底栏 | 换角度总结 · 追问 |
| 页脚提示 | 星标一句话建议 · AI生成 |

→ 本仓：**列表型结构 P0**；**图解式布局 P1**（自动纪要先保证结构化文本/可编辑块；图解增强后置，避免 4G/首版复杂度爆掉）。若用户升为 P0 再改。

## 录音中 UI（截图 · 产品 P0 关键）

智在「录音中」页元素：

| 元素 | 说明 |
|---|---|
| 顶栏标题 | 「新录音 MM-DD HH:mm」+ 可编辑铅笔 |
| 状态文案 | 「录音中」 |
| 大计时 | `HH:MM:SS` 已录时长 |
| 上限提示 | 如「录音时长上限为 60 分钟」 |
| 标重点 | 录音中打点/标记（本仓可 P1） |
| 波形 | 实时音量可视化 |
| 随手拍 / 随手记 | 会中附图/笔记（本仓 **P1**，非首版必达） |
| 底栏三键 | **丢弃(X)** · **暂停/继续(中)** · **完成(✓)** |

→ **本仓已定交互差异（以用户决策为准，非 1:1 抄智在）：**

| 本仓 P0 | 说明 |
|---|---|
| **点击开始** | 进入录音中 |
| **长按确认结束** | 对应智在「完成 ✓」，但用长按防误触；结束后 **自动上传** → Job |
| 暂停 / 丢弃 | **建议 P0**：暂停续录、丢弃不上传（实现成本低、现场必要） |
| 60 分钟上限 | **本仓默认 60 分钟**，配置可调（`MAX_RECORDING_MINUTES`） |
| 标重点 · 随手拍/记 | **P1** |
| 标题可改 | P0 或完成时可改 Meeting 名 |

## 用户对本仓的约束（已决策）

1. 主场景 = **现场实际录音**，不是腾讯会议系统声。  
2. 转写成功 → **自动**出纪要。  
3. 纪要结构可参考列表型模块 + 可选图解。  
4. **不要**每次自动 AI外脑灌屏；要 **我问你答** 的追问。  
5. 录音中：智在式计时/波形可参考；**结束手势 = 长按确认**（用户已定）。  
6. 用户可继续补图 → 本文件增量更新。
