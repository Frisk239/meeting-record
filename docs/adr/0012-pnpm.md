# ADR 0012 — 包管理器 pnpm

本仓 TypeScript monorepo / 应用使用 **pnpm** 作为包管理器（install、workspace、scripts）。

- **Status:** Accepted  
- **Date:** 2026-07-19  
- **Deciders:** 人（工程）

## Context

已定 Vite + React + Hono + Drizzle（ADR 0009–0011）。需固定包管理器以便文档与脚手架一致。用户选定 pnpm。

## Decision

1. Use **pnpm** (with `pnpm-workspace.yaml` when monorepo is scaffolded).  
2. Do not mix npm/yarn lockfiles as source of truth.  
3. Document scripts as `pnpm <script>` in README/AGENTS when app exists.

## Consequences

### Positive

- Efficient disk use; good monorepo support.  
- Aligns with many TS reference projects.

### Trade-offs

- Contributors must have pnpm installed (corepack enable pnpm is fine).
