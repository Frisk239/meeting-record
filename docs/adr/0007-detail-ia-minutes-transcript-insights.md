# ADR 0007 — 详情信息架构：纪要 · 原文 · 外脑(按需) · 追问子页

会议详情主导航为 **纪要（Minutes）· 原文（Transcript）· 外脑（Insights Board）**。  
**追问（Meeting Q&A）** 不是与纪要平级的强制主 Tab，而是 **纪要下的子页**，由纪要页 **右下角入口** 进入。  
**外脑** 可保留页面/Tab，但内容 **仅用户显式触发时生成**，转写成功后 **不自动** 灌屏。  
**探索** 类 Tab **不做**。

- **Status:** Accepted  
- **Date:** 2026-07-19  
- **Deciders:** 人（产品）

## Context

智在为 AI总结 | AI外脑 | 原文 | 探索，且外脑常自动生成。用户希望：追问沉到纪要里右下角进；外脑可留但不自动；探索直接砍掉。

## Decision

如上四条。视觉仍 Claude DESIGN；IA 可参考智在模块，不抄皮肤。

## Consequences

### Positive

- 主路径更短：录 → 转写 → 纪要；追问不抢主 Tab。  
- 外脑成本可控（不默认烧 token）。  
- 砍探索减范围。

### Trade-offs

- 外脑若做得浅，Tab 可能显得空 → 空态引导「点击生成」即可。  
- 追问藏在子页，需右下角入口足够显眼（对标智在底栏追问）。
